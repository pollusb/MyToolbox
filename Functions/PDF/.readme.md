# Fonctions de gestion des PDF

## Fonctionnalités

✅1. Extraire les données vers un fichier JSON
✅2. Extraire le texte d'un fichier PDF
✅3. Afficher le fichier JSON (pour ressembler au PDF)
✅4. Lister les fichiers qui ont un fichier JSON associé
5. Renommer la paire de fichiers PDF et JSON dans un format uniforme
6. Copier la paire dans un dossier (sur Google Drive, par exemple)

## Fonctions

| Fonction       | Synopsis                                          |
| ---------------|---------------------------------------------------|
| Export-PdfJson | Outil d'extraction de data via Google Gemini      |
| Export-PdfText | Outil d'extraction de texte                       |
| Show-PdfData   | Formater le data du json sur la console           |
| Get-PdfFile    | Pour savoir quels PDF ont un JSON associé         |
| Rename-PdfFile | Pour renommer la paire de fichiers PDF & JSON     |
| Copy-PdfFile   | Pour copier la paire vers un dossier Cloud        |

## Éventuellement avec une BD SQL

| Fonction        | Synopsis                                          |
| ----------------|---------------------------------------------------|
| Save-PdfFile    | Pour enregistrer la paire dans un dépôt/BD        |
| Restore-PdfFile | Pour extraire la paire vers un dossier            |
